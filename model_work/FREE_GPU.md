# Free GPU experiment

[Open the notebook in Google Colab](https://colab.research.google.com/github/sfstast/essaygrader/blob/main/notebooks/free_gpu_commentary.ipynb).

Sign in with your own Google account, select Runtime → Change runtime type → T4 GPU, then Run all. Free availability is not guaranteed. This project does not purchase compute, require paid model APIs, or publish a model. Notebook setup, weight downloads, fine-tuning and inference require internet access in that runtime. A free session may disconnect; download results before it ends.

The notebook collects the historical CC-BY OpenStax commentary dataset, resolves a pinned Qwen2.5-1.5B-Instruct revision and verifies its Apache-2.0 weight license, then runs one epoch of 4-bit QLoRA. It creates base-versus-adapter comparisons on the held-out test excerpts and downloads the adapter, provenance, license/attribution and review packet. It preserves prompt masking and refuses oversized examples. It does not silently deploy the result or report unreviewed commentary as accurate numeric grading. GPU execution and memory use remain unverified here; local checks validate notebook Python syntax and the data/software path only. Colab user sign-in and allocating a GPU cannot be performed from the current workspace.
